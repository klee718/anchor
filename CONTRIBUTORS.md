The project was built with the explicit intention of serving the broader community as a non-profit educational and spiritual resource.

## 🤝 Contributor Guidelines & Intellectual Property

### 1. Contribution Ownership
All contributions made to this repository are provided under the project's primary open-source license (see `LICENSE`). By contributing to Anchor, contributors agree that their contributions are dedicated to the ongoing mission of the project and its designating non-profit entity.

### 2. How to Contribute
We welcome community involvement, scholarly insights, and technical improvements!
* **Bug Reports & Feature Requests:** Please open an issue via the GitHub repository.
* **Code Contributions:** Submit a Pull Request targeting the `main` branch with clear commit descriptions.
* **Curriculum & Theological Review:** Suggestions for new lesson paths, translations, and scripture commentary are encouraged.
